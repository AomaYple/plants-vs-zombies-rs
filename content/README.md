# 原创游戏内容

本目录存放本项目原创的版本化游戏内容，使用项目 MIT 许可。它与 `assets/original/` 的原版参考资源分别维护，不进入原版资源清单。

[白天开发关卡](levels/development-day.json) 使用 schema 1、规则 2.0 和 `basis: development`。seed 为 7，初始阳光为 150，模拟频率为 60 Hz；23 个规则标量和十项有序波次逐项迁移自核心 `SliceRules::development()`，全部属于尚无原版测量证据的开发参数。

内容格式由 `pvz-data` 的白天 DTO 定义，对象字段完整且严格，波次数组保留输入顺序。格式解析不替代核心的支持版本与游戏规则有效性检查；原有核心默认规则保留为独立迁移对照。当前消费者为 data 集成测试；后续应用将按设计在编译时嵌入此 JSON，使 native 与 Web 消费相同字节，运行时无需读取源文件或依赖原版程序。

`pvz-data` 集成测试直接加载此文件，核对全部参数、波次和序列化往返，并覆盖未知、遗漏、重复字段、数值类型与版本/标识符格式错误。
