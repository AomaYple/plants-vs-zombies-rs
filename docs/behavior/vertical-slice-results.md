2026-10-11 用户重新授权执行近期计划。本轮已完成开发切片的本地工程验收，输入/重开/截图退出修复、CLI/XML/基准合同补强与音乐生命周期修复均通过局部独立规范及质量复核，覆盖率和最终计时已汇总。本轮整分支独立规范与质量复核已通过，Git 交付按对应 PR 和 CI 记录核验；本记录不表示原版行为还原或六平台支持全部完成。任务状态以 [实施计划](../superpowers/plans/2026-10-07-foundation-and-asset-audit.md#任务状态与恢复入口)为准。

## 功能与合同

纯模拟保持引擎和 I/O 独立。5×9 白天棋盘已实现向日葵、豌豆射手、普通僵尸、豌豆、阳光、割草机和固定十只波次；支持选卡、费用/冷却、种植、收集、铲除、暂停/恢复、重开和胜负。输入按原始提交顺序处理，摘要包含影响未来演化的初始合同、规则、实体、计时、ID、波次、选择与终局。

空棋盘入口保持规则 1.0，新切片使用明确的开发规则 2.0，schema 仍为 1。60 tick/秒以及生命、速度、碰撞和规则阶段顺序都是开发参数，详见 [开发切片合同](development-slice.md)。原版时基、间隔、碰撞与事件顺序尚未测量；内部回放一致性不能作为原版一致性的证据。阶段标记 `development-slice-validated` 只表示开发工程合同通过本地验收。

Bevy 应用读取清单登记的背景、94 张图像和四类事件音效，中文界面展示选卡、阳光、冷却、铲除、暂停、重开和胜负。六类对象采用登记静态构图，尚未接入完整 idle/射击/啃食/死亡动画混合、原版粒子和 MO3 音乐。

本轮修复和回归保护覆盖以下消费者合同：

- P/Space/R/E/M 与指针事件使用同一指定窗口的有序消息流，过滤重复、异窗和失焦键盘输入；同批重开后的铲除选择保持，重开后的点击不提交旧阳光 ID，重开前收集保留原顺序。
- native GPU 截图请求后以真实时钟等待最多 30 秒，保存成功、失败或超时只交付一次最终退出结果；无回调及迟到回调有无 GPU 边界测试。
- 音乐每帧在模拟推进和事件消费后同步最终暂停状态；尚未建立 AudioSink 的请求更新原生 PlaybackSettings，已有 sink 使用成熟 pause/play 能力。
- CLI stderr 不可写时保留参数错误退出 2、资源错误退出 1；两个 Windows 真实子进程闭管道回归能在原实现复现 panic/101。
- XML 新增四项语义测试，覆盖显式空/缺省/零、CDATA 与实体拼接、重复 Field/SystemField 和子树原文顺序、粒子缺省及显式空标量。

冒烟日志中的“帧末tick”表示本帧事件消费后的模拟 tick，保留相对事件顺序，不能解释成每条事件的实际发生 tick。

## 基准合同与最终计时

三个 package 共十个 Criterion 场景采用 `std::hint::black_box`，不依赖窗口、音频设备或原版资源。初始化与种植预热在计时外：切片共享场景在 tick 45 有 5 株向日葵、40 株射手，余额 5750、初始无僵尸、未来固定波次总量 100；1000 次调用实际推进 1000 tick，到 tick 1045 仍为 Running。终局后的同一函数推进 0 tick、摘要不变，自动测试保护这两种合同。100 只表示波次总量，不能写成初始同时存活数量或推导整游戏帧率。

首轮恢复计时与本项目 Web 渲染活动重叠，仅保存为探索记录 `artifacts/validation/resume/bench-exploration-web-active/`。关闭自有浏览器、恢复临时视口、停止自有 HTTP 服务，并确认无本项目 Cargo/app 活动后，运行 `cargo bench --workspace --locked`，十个场景最终计时 exit 0，命令耗时 118.052 秒。没有控制维护者的其他活动、CPU 电源状态或温度，不声称整台机器完全空闲。Criterion 比较输出因环境改变显示 improved，不能解释成代码优化收益。
