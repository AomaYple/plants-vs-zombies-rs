## 解包一致性

```text

```

核对使用大小写无关的路径匹配，适用于本次 Windows 输入比对。
跨平台资源索引必须另做大小写碰撞检测，不能因为本机可加载就假设 Linux 文件路径可直接复用。
资源清单中的每个引用及运行时可用性尚未逐项验证；字节一致只说明这份拆包没有缺失或改写包内文件。

## 尺寸与动画证据

尺寸来自 PNG IHDR 与 JPEG 帧头读取，不依赖截图推测。

| reanim/Zombie.reanim | 首行 fps = 12 |

800 × 600 作为首阶段逻辑视口的设计基准。1400 像素宽的背景是较大的场景资产，不应整张挤进 800 像素视口。
背景裁剪、偏移和场景平移位置必须通过原版画面比对确认。
12 fps 是这两个动画的资源时间轴值，不是游戏逻辑 tick，也不能推广为全部动画的帧率。
