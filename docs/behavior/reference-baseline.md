## 尚未验证的事实

- 原版模拟 tick 时长、攻击判定更新顺序和随机数算法。
- 棋盘点击区域、碰撞盒、滚动背景的实际偏移。
- Reanim 完整插值、稀疏字段继承和特殊帧含义。
- MO3 音乐在选定跨平台音频方案中的解码与循环行为。
- 六平台的完整构建、运行、音频、存档和输入支持；已有分项证据及仍待验收范围见[路线图](../roadmap.md#横向证据与平台)，不能把部分构建或实跑扩大为全平台支持。

`pvz-core` 当前使用 60 tick/秒作为开发参数，并以显式时钟、固定 RNG 算法和状态摘要建立内部回放合同。这些实现合同不改变上述原版事实的未验证状态；原版行为验收前必须用同条件运行测量替换或确认开发参数。

以上事实要通过相应测量或实现阶段验证。不得把此前讨论中的 60 Hz 建议写成原版已知规格。
公开证据以文字、数值、资源清单和文件指纹为主；版本化参考资源位于 `assets/original/`，原版截图、录像和临时资源派生产物保留在本机忽略目录。
