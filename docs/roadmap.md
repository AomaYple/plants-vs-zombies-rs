# 项目路线图

当前产品入口是[七阶段集中开发总计划](superpowers/plans/2026-10-17-phased-development.md)，当前任务见[第一阶段实施计划](superpowers/plans/2026-10-17-phase-1-day-combat.md)。每阶段集中开发多项关联需求，自动化验证持续进行，整批具备后集中实机测试、调整和验收。

截至 2026-10-18，白天单关、双终局、暂停/重开和向日葵 idle 已有交付，普通僵尸 walk 已有工程与部分 Web 证据；B1 平台缺项及 B2 啃食/死亡需求迁入阶段 1。测试优化、规则和仓库卫生整合已交付。2026-10-18 的全仓维护完成规则入口、项目元数据、文档导航、跟踪文件格式和目录消费者审计，未改变产品范围或验收结论。

## 七阶段

| 阶段 | 玩家得到的版本 | 状态 |
| --- | --- | --- |
| 1 完整白天战斗体验 | 现有单关的动作、战斗反馈、音效、暂停、终局和重开一致 | 详案已建立，游戏开发待启动；承接 B1/B2 |
| 2 白天冒险与进度 | 防守/护甲策略、至少两关、选卡、菜单、解锁和保存继续 | 待启动 |
| 3 夜间与泳池 | 对应环境、角色、代表性关卡和冒险接入 | 待启动 |
| 4 雾、屋顶与冒险通关 | 特殊环境、最终遭遇、通关及失败重试 | 待启动 |
| 5 附加模式与外围系统 | 小游戏、生存、谜题、花园、图鉴/商店与共享进度 | 待启动，启动时确定关联需求批次 |
| 6 内容补全与还原调整 | 全量内容、视听完善、按证据修正行为 | 待启动；原版测量持续开展 |
| 7 六平台适配与发布 | 各平台正常安装/打开、游玩、保存和重启恢复 | 待启动；风险探针提前开展 |

每阶段形成完整可玩版本，保留既有流程；阶段内部任务不各自要求完整实机交付。多个目的提交/PR 仍分别完成适用门槛；阶段完成必须包含必要实机与交付证据。旧 S 编号只用于历史来源，映射见[总计划承接表](superpowers/plans/2026-10-17-phased-development.md#历史计划承接)。

## 当前下一步

1. 按阶段 1 计划确定可靠的攻击者/目标、死亡锚点和事件兼容合同，持续自动化验证。
2. 集中完成普通僵尸啃食/死亡、植物/投射物必要反馈、时钟、音效、UI 与输入一致性。
3. 完成工程检查并固定待测版本，统一 Windows/Web 实机测试与调整，同时补齐 B1 的无遮挡动态图、失败冻结、resize 和操作后诊断。
4. 达到阶段标准后交付，根据实际接口细化阶段 2；缺少环境时保留待验，继续无依赖的独立工作。
