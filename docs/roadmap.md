# 项目路线图

路线按可独立验证的交付阶段排列，具体任务顺序见 [实施计划](superpowers/plans/2026-10-07-foundation-and-asset-audit.md)。长期约束见 [项目原则](principles/README.md)，提交验收见 [贡献指南](../CONTRIBUTING.md)。

跨平台支持目标包含 Windows、macOS、Linux、Web、Android 和 iOS。桌面与 Web 先行，移动端随后接入；所有平台均须分别完成构建与最小运行验收。

当前已完成 P3 白天开发切片的本地工程验收，切片及质量补强的局部独立复核通过；证据整合与最终整体复核已通过，Git 交付按对应 PR 和 CI 记录核验。原版时基、间隔、碰撞与事件顺序尚未测量，完整原版行为、动态表现和其他目标环境仍未验收，详见 [切片验收结果](behavior/vertical-slice-results.md)。P0 的仓库与参考文件核对已完成；3,228 个解包资源和 `main.pak` 已纳入版本化资源清单。资源使用前校验清单和指纹，原版行为测量另确认本机 EXE 身份和可用性。

## 横向质量门槛

每个阶段持续执行 [工程原则](principles/engineering.md)与 [游戏开发原则](principles/game-development.md)，持续义务不使用一次性勾选表示永久完成。本节跟踪当前机制及其尚未闭合的验收：

- [x] 首次 package 已提交锁文件、继承 lint 并启用格式、检查、测试、Clippy、文档和依赖审计 CI。
- [x] 已建立文本/二进制分类、清单指纹与来源检查，原版可执行文件和未登记载荷继续禁入。
- [x] 已随实现建立核心回放、覆盖率报告和热路径基准；六平台状态与限制已有独立记录。
- [x] 完成 CLI 输出失败、XML 空/缺省/CDATA/重复顺序、截图退出和音乐生命周期的回归补强，取得默认/all-features 独立覆盖率报告。
- [x] 核对基准实际预热、波次总量、推进 tick 和终局冻结合同；最终计时按实施计划独占复测并记录范围。
- [x] 完成当前实施范围的文件、模块、API、依赖消费者和最终整体复核；优化结论附同条件性能与行为证据。
- [ ] 各平台发布前完成相应构建、运行和资源/许可验收；未来平台继续按 P6 推进。
