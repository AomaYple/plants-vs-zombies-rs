# 测试策略

测试默认并行运行。只有共享外部状态、真实窗口、音频设备或平台生命周期测试无法隔离时，才对最小范围使用串行执行，并记录原因。

适用的测试层级包括：

- 单元测试：纯函数、状态转换、数据校验和坐标变换。
- 集成测试：crate 边界、资源报告、命令/事件合同和回放。
- 边界/属性测试：空棋盘、最大实体、时间边界、路径大小写、损坏输入和重复命令。
- 平台契约测试：窗口尺寸、高 DPI、输入映射、存档介质和生命周期。
- 手工端到端测试：真实窗口、音频、Web 浏览器和移动设备；报告平台、版本和限制。

测试不复制原版资源。公开夹具使用原创的最小数据；本机资源验证不得把原版载荷写入仓库。

覆盖率用于发现未测试区域，不替代测试设计。推荐使用 `cargo llvm-cov` 生成 workspace 报告，并关注核心规则、资源错误分支和跨平台边界；不要为了追求数字而加入无意义断言。
