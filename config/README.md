# 本地配置

local.example.toml 是计划中的配置格式示例，不是已经接入的运行配置。
未来应用在开发环境从仓库根目录解析相对路径；打包版本由平台资源提供器解析，不依赖工作目录。

用户将示例复制为 local.toml 后，可把 assets.root 改为现有解包目录的绝对路径。
local.toml 被 Git 忽略；README、测试和 CI 不保存用户的绝对路径。
未来启动接口允许环境变量 PVZ_ASSET_ROOT 覆盖本地配置，CLI 显式 --asset-root 的优先级最高。
命令行参数 > 环境变量 > 本地配置 > 自制占位资源；选择原版模式而路径无效时报告错误，不悄悄切换素材。
