# pvz-core

已注册的纯 Rust 模拟 crate，当前提供空棋盘固定 tick 推进、阳光命令与事件、确定性 RNG 封装和状态摘要；实体、碰撞及完整回放格式尚未实现。

`GameState::step` 按输入切片的提交顺序执行命令，事件保留执行顺序。空棋盘与阳光命令没有随机规则消费者，不消耗 RNG。时钟达到 `u64::MAX` 后以中文诊断拒绝推进，世界状态和命令不发生部分修改。

`StateDigest` 纳入关卡、完整时钟、阳光、RNG 完整 `(u128, u128)` 内部状态和当前开发规则版本。开发时钟为明确标记的 60 tick/s，规则为 `RulesVersion::current()`；两者都不构成原版行为还原证据。状态摘要包含关卡字符串，因此可克隆但不可 `Copy`，不是序列化存档或持久回放格式。

`DeterministicRng` 是锁定 `oorandom 11.1.5` 的 `Rand64` 最小领域包装，以显式 `u64` seed 转换为 `u128` 初始化，不读取系统熵。当前选择不代表原版随机算法；首次验收前已替换原自写 xorshift，旧开发 RNG 输出及状态与此合同不兼容。规则 1.0 尚未产生已验收/发布规则或持久回放；后续已验收或持久回放行为变化必须版本化。

`tests/determinism.rs` 使用原创最小输入覆盖顺序、边界、状态差异和连续多 tick 回放。`benches/stepping.rs` 提供带开发规则版本、规模和 seed 的空棋盘及命令推进场景，初始化在计时区间外；只编译基准不能作为性能测量。
