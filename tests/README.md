# 测试数据约定

公开测试夹具和逻辑回放必须原创、最小、可审阅且不复制原版资源内容。

[`fixtures/`](fixtures/README.md) 放共享格式夹具；当前固定输入回放直接位于 `pvz-core` 的集成测试中，尚无独立持久回放文件或加载器，不预建空回放目录。

以后持久回放只保存版本化的初始合同、RNG 算法/seed 和有序逻辑输入，不复制图片、音频或原版文本；需要资源时引用清单的参考基线 ID。格式与目录依据实际消费者建立。

资源集成测试可读取 `assets/original/`，core 测试保持资源无关。原版截图、录屏、EXE、存档和临时资源包保留在被忽略的本机目录。
